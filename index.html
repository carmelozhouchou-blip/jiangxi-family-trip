MAKE · 手绘

在瓷都，带走一件自己画的

不用会画画。选一只马克杯或小碗，用釉下彩画完，店家施釉、烧制、寄回家。五个人各画一件，大概 2.5 小时。

首选 · 省心¥198/位

陶公塾

陶溪川 C6 栋 · 9:00–18:00（周末到 21:00）

含素坯、颜料、指导、施釉、烧制和邮寄。5 人约 ¥990，2.5 小时。动车方案没有登机牌 85 折。

  • 选平缓器型：马克杯、小碗、盘子
  • 铅笔轻稿，釉下彩薄涂多层
  • 烧制 7–15 天，成品寄回家
预算优先

老厂画室

老厂 798 / 雕塑瓷厂。驻场 ¥20–30/人，素坯 ¥5–45，烧制 ¥1–2/cm；5 人约 ¥400–600。适合想画一整天、画大件的人。

慢逛组合

三宝言予窑

三宝村。素坯 → 彩绘 → 施釉 → 1280℃ 烧制；价格以店为准。适合把三宝村和手作放在同一天。

不想画的人可以在旁边逛店、喝茶；按实际画的人数付费。周末陶公塾早订。

STAY · 住宿

四晚不换酒店，把行李放下

按你们的住法：夫妻大床房 + 爸妈和妹妹双床房。两种选法，一种更省空间，一种更省心。

EAT · 吃什么

辣是江西的底色，点菜先说微辣

景德镇的早餐在抚州弄，晚饭在陶溪川或浙江路；篁岭吃天街，三宝吃煨鸡。五个人点一只鸡 + 3–4 个菜 + 汤刚好。

抚州弄 · 早餐

冷粉 / 油条包麻糍 / 饺子粑

陶姐冷粉的牛肉冷粉，配一碗牛骨粉；7–9 点最全。给妹妹加一份不辣的饺子粑。

陶溪川 · 晚饭

欧记大排档 / 小黄鱼

炒碱水粑、碱水粑炒腊肉、本地小炒；逛完夜市就能回酒店。

御窑 · 陶阳里

堂前 · 瓷泥煨鸡

瓷泥煨鸡提前 1 小时电话订，碱水粑炒鸡蛋、苦槠豆腐也稳；适合 D2 晚饭或 D5 午饭。

三宝 · 午饭

三宝别院 / 9494

荷叶 + 竹叶双包的瓷泥煨鸡；孩子喜欢 9494 的窑烤披萨，大人喝不空山咖啡。

篁岭 · 天街

糊豆腐 / 笋尖烧肉 / 汽糕

天街食府吃正餐，路边补汽糕、清明粿、油煎灯；山上选择少，别等到 13 点才吃。

浙江路 · 夜宵

李记碱水粑

碱水粑炒腊肉、油炸清汤；17:00–02:00，适合 D3 从篁岭回来。

必点：瓷泥煨鸡（堂前 / 三宝别院，提前 1 小时订）、碱水粑炒腊肉、糊豆腐、冷粉、饺子粑。

辣度：默认中辣，给爸妈和妹妹点“微辣 / 不辣”；冷粉少放辣椒和橘子皮。

TIPS · 带爸妈和妹妹

把这几个细节记住，
路上少累一半

爸妈的节奏

D2 / D4 / D5 都是平路；D3 篁岭走短线：天街 → 晒秋台 → 五桂堂 → 索道下。带防滑鞋、登山杖，累了在天街茶馆等。

妹妹的玩法

篁岭冒险森林、垒心桥让妹妹和一位大人去；手绘选马克杯最好画。带学生证 / 身份证，门票按学生 / 儿童价。

天气与穿衣

11 月景德镇 8–19℃，婺源白天 15–22℃，早晚差 5–8℃。洋葱式穿衣、防滑鞋、雨具、驱蚊液。

瓷器怎么带

烧制 7–15 天，店家邮寄；让店家双层包装，别放行李箱底层。陶溪川文创可手提，瓷器尽量随身。

出发前 48 小时：再确认 12306 座位、酒店加床 / 早餐、博物馆预约、篁岭天气和包车司机电话。行程会随天气和预约微调，页面随时可以再改。
